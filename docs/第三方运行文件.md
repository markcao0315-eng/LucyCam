# 本地图像追踪依赖

生产文件：`dist/vendor/opencv-4.13.0.js`（10,964,323 字节，包含 base64 WASM，无独立 wasm 文件）。首次点击实时引导时在 classic Worker 内加载，普通相机和开关关闭时不下载。

- 下载来源：https://docs.opencv.org/4.x/opencv.js ，2026-10-06（America/Toronto）。4.12.0 和 4.10.0 固定文档目录下的 opencv.js 均实际返回 404；下载后通过 `getBuildInformation()` 核实为 **OpenCV 4.13.0 / Version control: 4.13.0**。
- SHA-256：`63366510248adf3a7eddf3e793dd825404efb7df3749f4d6f8557c7fa4ca8aa0`。
- 生产运行只读取仓库内固定文件，绝不请求浮动 `4.x` CDN；升级须重新测量、核验版本并更新哈希。此文件未改动上游代码。
- 许可证：`dist/vendor/opencv-LICENSE.txt`，来自 https://raw.githubusercontent.com/opencv/opencv/4.13.0/LICENSE 。OpenCV 主体采用 Apache 2.0，保留其关于第三方组件的说明。构建说明：https://docs.opencv.org/4.x/d4/da1/tutorial_js_setup.html 。
- 已在 Chromium Worker 验证 `goodFeaturesToTrack`、`calcOpticalFlowPyrLK`、`cvtColor`、Mat。此构建的 `cv.then()` 回传自身，不能直接 `await cv`；加载器用对象包装处理。
- Chromium 报告 WASM 线性内存为 128 MiB；这是已分配容量，不代表全部驻留内存或总内存使用。移动 Safari 加载时延与内存压力未实测，失败会保留普通相机。

测试依赖固定为 `@playwright/test@1.56.1`（锁文件包含传递依赖）；通过 `npm ci` 和 `npx playwright install chromium` 安装，使用 Chromium 141.0.7390.37 / build 1194。测试不依赖全局 Playwright，不读取生产密钥。
