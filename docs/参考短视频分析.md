## 本轮落实

默认AI自选场景 → 一次Gemini规划主体、区域和色彩 → 本地真实OpenCV追踪目标圈 → 对准后数字裁切放大并应用推荐 → 显示可拍，按快门（可选自动拍一张） → 从未加效果的同一裁切照片调整风格、曝光、对比、饱和，或还原色彩/AI推荐 → 保存。

默认构图优先允许最多5×相对当前取景的数字裁切；画质优先扩大选区以尽量保留720短边/100万像素，并最多2×。显示真实裁后尺寸，不放大输出像素冒充细节。两种方式都保护主体、相同比例和边界。

明暗调整作用于图像像素，不声称设置硬件ISO、快门或恢复溢出高光。六种本地风格包括原片、清透、暖阳、胶片、黑白、鲜活；鲜活不冒用其他App的品牌滤镜或参数。OpenAI生成式自然修图仍是拍后可选按钮，不自动上传每一张成片。

验证区分真实算法处理合成像素、模拟模型协议与实际手机/模型审美。自动测试通过不能证明真实场景选得最好，也不能代替手机保存与画质验收。
