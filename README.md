# LucyCam

中文手机网页相机。普通拍照与滤镜在浏览器本地完成；点击「AI 构图」时，仅将当前画面缩小后经 Render 中转给 Google Gemini，返回构图建议和裁切预览。实时入口是场景发现相机：AI 自主选主体和区域，真实追踪引导对准后数字放大、应用推荐风格与曝光，再按快门（可选自动一张）。0.9.1 增加结构构图、字段恢复和本地取景恢复，保留五套原创风格、按主体区域与像素颜色估计的局部补光、真实构图/风格缩略图，以及完整底图保留。普通拍照和导入也能本地切换风格；AI 拍后可切换候选裁切和完整底图。OpenAI自然修图保留为独立可选动作；真实模型审美和手机体验需另外验收。

演示网址：https://lucycam.onrender.com

代码仓库：https://github.com/markcao0315-eng/LucyCam

## GitHub 与 Render 部署

仓库根目录就是本地 `lucycam-web` 目录。GitHub 顶层应直接看到 `package.json`、`server.mjs` 和 `render.yaml`。

1. 在 Render 创建 `LucyCam` Project，环境使用 `Production`。
2. 添加 **Web Service**，连接 GitHub，选择 `markcao0315-eng/LucyCam` 私有仓库。只授权此仓库即可。
3. 按下面的配置部署：

| 字段 | 值 |
| --- | --- |
| Name | `lucycam`（已被占用时加后缀） |
| Language / Runtime | `Node` |
| Branch | `main` |
| Root Directory | 留空 |
| Build Command | `npm ci && npm run check && npm test` |
| Start Command | `npm start` |
| Health Check Path | `/healthz` |
| Environment variable | `NODE_ENV=production` |
| Instance | 初次连通测试选 Free；实际使用可换常驻付费实例 |

也可以用仓库的 `render.yaml` 创建 Blueprint。它默认创建一个 Free Web Service；手动 Web Service 与 Blueprint 二选一，避免重复创建。当前不需要数据库或持久磁盘。未配置 AI 时，普通拍照仍可使用。

Render 自动设置 `PORT`；程序监听 `0.0.0.0`，运行版本由 `.node-version` 指定为 Node 24。

部署成功后打开 Render 实际返回的 HTTPS 网址。`/healthz` 应返回 `{"status":"ok"}`，部署本次代码后 `/api/status` 显示版本 `0.9.1`。`aiComposition: true` 仅表示配置齐全，不代表已经验证 Google Key 的有效性。

GitHub 私有仓库只控制源码访问；Render 的 Web Service 网址默认可公开访问。相机页面可公开使用，收费 AI 接口要求家庭访问口令。

API 密钥放在 Render 的 Environment 中，不写入前端代码、聊天或 GitHub。`.env` 和日志已在 Git 忽略规则中；`.env.example` 仅作配置说明。

## 配置 AI

在现有 Render Web Service → Environment 中添加并保存部署：

| 变量 | 值 |
| --- | --- |
| `GEMINI_API_KEY` | 你自己的 Google Gemini API Key |
| `LUCYCAM_ACCESS_CODE` | 自己设置的至少 12 位私人口令，手机上输入这个口令 |
| `GEMINI_MODEL` | 可选，默认 `gemini-3.1-flash-lite` |
| `AI_DAILY_LIMIT` | 可选，默认每 UTC 日 200 次尝试 |
| `AI_HOURLY_LIMIT` | 可选，默认每 UTC 小时 60 次尝试 |
| `LIVE_GUIDANCE_ENABLED` | 实验功能，只有字符串 `true` 开启；默认关闭 |

手机刷新页面，开启相机，点击「AI 构图」，输入家庭口令解锁，再点击一次开始分析。绿色框表示 AI 建议保留的范围；点「预览这张裁切照片」，再保存到相册。裁切使用手机内存中的较高分辨率原帧，上传的只是最长边 1024 像素的 JPEG。滤镜在导出时本地应用，AI 读取的是无滤镜画面。

如果按钮显示 AI 未配置，检查两个必填变量和口令长度，再确认最新部署成功。若出现 Google 服务错误，检查 Key、Gemini API 权限、所选模型和项目额度。配置变量后仍需在手机实际点击一次验证；自动测试不使用真实 Key，也不产生 AI 费用。

口令验证后使用 12 小时 HttpOnly / SameSite=Strict 会话，生产环境增加 Secure；修改口令会使旧会话失效。POST 请求限制为同源 JSON；默认只允许单个分析并发、每 5 秒一次，登录每 15 分钟最多 30 次尝试。调用上限为**单进程内存计数**，重启会重置，多实例各自计数，不是账单硬上限；失败的模型请求也计入次数，无自动付费重试。当前面向单实例家庭使用。

LucyCam 不把照片存入文件、数据库或应用日志，但 Google 会按其服务条款处理上传图片；个人照片建议确认 Google 项目的计费和数据使用设置。[Gemini API 定价与数据使用说明](https://ai.google.dev/gemini-api/docs/pricing)。

官方文档：[Render Web Services](https://render.com/docs/web-services)、[Render Projects](https://render.com/docs/projects)。

## 功能

- 摄像头权限、前后镜头切换，自拍预览与保存均为镜像。
- 3:4 / 1:1 / 9:16 中心裁切；网格和构图参考不写入照片。
- 保留六种普通相机滤镜；AI 取景与拍后编辑新增清透旅拍、森系电影、暖光胶片、都市杂志、夜色氛围。真实缩略图可比较风格，支持浓度、曝光、对比、饱和与推荐还原。
- 3 / 10 秒定时拍照，前后台切换时停止相机。
- 本地照片导入（保留原比例）、JPEG 导出、系统文件分享和下载。
- 主屏幕图标与安装清单。当前需要联网加载，不保证离线启动。
- 单帧 AI 主体描述、中文构图建议、保持原比例的裁切预览与照片导出；访问口令、调用限额、错误提示。

## iPhone 演示

1. 用 Safari 打开部署后的 HTTPS 网址。旧 Sites 演示版是私有的；新 Render 部署不要求 ChatGPT 登录。
2. 点击「开启相机」，允许摄像头权限。
3. 选择色彩和场景，调整取景，按白色快门。
4. 点「保存 / 分享」，选择「存储图像」。若没有这一项，长按预览图保存。
5. 打开 iPhone「照片」确认保存成功；分享完成不等于已保存。
6. 可从 Safari 分享菜单选择「添加到主屏幕」。不需要 Apple Developer、Xcode 或 TestFlight。

照片只暂存于页面内存，刷新或关闭前应保存。「下载图片」可能进入「文件」而非「照片」。权限被拒绝时，调整 Safari 的网站相机权限后重试。微信等应用内浏览器不作为当前测试目标。

## 开发

Node.js 运行 `npm run dev`，本机打开 http://127.0.0.1:4173 。iPhone 不能把这台电脑的 localhost 当成演示地址，也不要使用不支持相机权限的普通局域网 HTTP 地址。手机请使用正式 HTTPS 网站。

`npm run check` 检查语法；`npm test` 验证裁切、分辨率上限、像素滤镜、后台健康检查、静态资源、私有文件隔离、AI 会话/限额/超时/返回值校验。AI 单测注入模拟 provider，无外部 AI 请求。`npm start` 启动与 Render 相同的服务器，本地默认端口为 10000。本地调试时通过 shell 环境变量传入配置，程序不会自动读取 `.env`。

## 实时 AI 引导（0.9.1，结构构图与错误恢复）

现有Render服务保持LIVE_GUIDANCE_ENABLED=true；不开新服务、不改套餐。默认AI自选，无需先选人像；旧场景偏好折叠保留。两段参考的可见行为与证据边界见[参考短视频分析](docs/参考短视频分析.md)。

1. 后置相机点「AI 帮我拍」，每轮上传一帧给Gemini；首次家庭口令解锁后再次点击启动。AI返回焦点主体、推荐区域及最多两个备选、原创风格、曝光/对比/饱和、局部光影及理由；仍为同一请求，无自动付费复评或重试。
2. 按目标圈轻转手机。黄色框标出主体，青色框标出AI选择的区域；圈和选区使用真实图像追踪结果。对准停稳后约450ms过渡到实际裁切，自动应用推荐色彩。
3. 默认显示“构图和色彩已就绪”，按白色快门拍摄。也可在启动前勾选自动拍一张；每轮最多一张，不叠加倒计时。就绪时可调整风格、曝光、对比、饱和，或切换构图/画质优先。
4. 构图优先允许相对当前取景最多5×数字裁切；画质优先最多2×并尽量保留720短边/100万像素。两者都保护边界；人物/物体完整保留，结构场景保护所选区域的核心，允许裁掉延伸的墙面与线条，显示实际倍率与裁后尺寸。没有光学变焦或插值超分承诺。
5. 快门复制新到达的完整当前帧并停止追踪，按现有8MP/4096上限保留底图，推荐裁切与备选变换到该帧坐标。拍后缩略图在同一底图上真实渲染，可选择不同构图或完整底图、比较五种氛围、还原色彩或恢复AI推荐；不叠加上次编辑。曝光EV是本地像素编辑，不是硬件ISO/快门。全尺寸调色放到独立Worker，关闭/取消/后台会中断等待并阻止旧结果发布。
6. 用户点击分享/下载或长按保存。OpenAI修图仅通过成片上的独立按钮触发，主流程不会自动调用OpenAI。

追踪使用完整未镜像视频、真实OpenCV LK和背景仿射补偿。AI选中小主体时，会在最初参考图对应区域追加局部角点，并验证往返光流与背景运动一致；不会把当前错误位置直接设为可信参考。subject类型保留主体内至少4个特征及背景校验；structure类型使用全景分布的特征、原始参考残差和覆盖要求，不要求空墙或结构核心内也有角点。严重遮挡、强视差或独立运动仍可能丢失。

模型返回先分组件恢复：坏备选单独丢弃，裁切在边界/保护内容约束下联合调整，坏风格回原片、光影参数限幅、无效数值回零。返回有限原因代码，不记录照片、密钥或模型原文。缺失主体、拒绝规划、无法解析的回复或服务连接故障，客户端从同一参考图的边缘分布生成保守本地建议，标明“本地构图”，不声称完成了模型审美分析。没有人物、杂乱或没有突出物体不应被提示词视为拒拍理由。

若最初画面缺少特征，进入FRAMING并提示带入墙角、窗框、桌沿；不显示虚假目标圈，也不自动判定对准。用户可直接按白色快门拍当前新帧，或移动至有纹理的场景后自动重建本地参考、重新对准停稳。重建使用同一个Worker、全新像素与帧编号，旧参考包隔离；不重新请求Gemini。纯色墙面不保证自动拍摄。

对准半径为取景短边7.5%，对准400ms、变焦450ms、稳定300ms；采样新鲜度600ms，短暂停顿自动等待恢复，2.5秒持续无新帧停止。引导参考20秒，就绪/低纹理取景最多60秒；始终检查最新真实帧。照片复制后不再用帧年龄取消编码，但用户取消、后台和旧轮次仍禁止发布。

镜头/比例/方向/视频尺寸/前后台变化作废本轮。丢失时给具体方向和重试入口，不自动增加收费请求；普通相机、单帧AI、诊断、会话和限额保留。动作辅助为可选DeviceMotion提示，不积分成行走距离，拒绝授权不影响图像引导。

拍后「对比完整原片」显示未裁切和调色的底图，保存按钮保存上方当前成片。「本张处理记录」包含AI期望倍率、拍摄实际倍率、是否适配、当前裁切像素、风格强度及区域光影是否执行；仅在页面内展示，不上传日志或照片。

五套风格使用原创明暗曲线、绿色等颜色权重、冷暖分区与肤色类颜色保护，不复制品牌胶片参数。局部补光由AI给出有界主体/背景EV，按真实主体范围内外的颜色分布估计软区域并沿图像边缘平滑；颜色难以区分时跳过。它不是语义人像/皮肤分割、发丝抠图或生成式重打光，也没有新增磨皮、景物生成或自动OpenAI上传。

部署后顶栏应显示v0.9.1；先保存未保存照片，再使用 https://lucycam.onrender.com/?v=0.9.1 核对顶栏。以实际线上版本和资源核验为准，不以本地测试代替部署验证。预览最长边360、最多10fps；导出按真实裁切像素及既有8MP/4096上限。真实Android/iPhone画质、成功率、原生保存仍待验收。

## OpenAI 自然修图（拍后可选）

在现有Render Environment添加 OPENAI_API_KEY，保存并部署；无需更换Gemini Key或家庭口令。可选 OPENAI_IMAGE_MODEL 默认 gpt-image-2.5-sunburst，OPENAI_IMAGE_QUALITY 默认 high。/api/status 的 retouch.configured 只验证配置存在，不验证余额、模型访问权限或实际效果。Key不进入前端、仓库或聊天。

默认推荐 GPT Image 2.5 Sunburst，官方将其定位于编辑精度优先；使用 POST https://api.openai.com/v1/images/edits，JSON images 中传入一张JPEG data URL、固定服务端提示词、n=1、size=auto、quality=high、output_format=jpeg。输入最长边2048，原始拍摄照片仍留在本页供保存；输出尺寸和裁切由模型决定，不强制每张都裁切。不发送旧模型的input_fidelity参数，不自动切换模型或重试。官方资料：[模型](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)、[编辑API](https://developers.openai.com/api/reference/resources/images/methods/edit)、[生成指南](https://developers.openai.com/api/docs/guides/image-generation)。查询日期2026-10-07。

固定修图规则在retouch.mjs：构图、轻微扶正、补光、白平衡、克制调色和轻磨皮，优先保留身份、年龄、五官、体型、动作、衣物及原场景关系；仅必要时小幅补足边缘内容。不能承诺生成式模型逐像素保真或准确还原画外内容，输出需与原片对照。它可能耗时一两分钟；界面不给虚假百分比。标准图像token单价为输入每百万8美元、输出每百万30美元，另计提示词；实际单张费用取决于尺寸与token消耗，不能拿其他模型单张价作本模型报价。

成片预览中主动点击“OpenAI 自然修图（可选）”才上传当前成片。处理期间显示等待状态，成功后可切换“查看原片/查看AI成片”并分别保存。失败时原片保留，可主动查看保存；不把原片冒充修图结果。取消、后台及旧轮次的晚返回结果不得发布。

/api/retouch 复用原家庭会话和同源检查，使用独立 RETOUCH_DAILY_LIMIT=20 / RETOUCH_HOURLY_LIMIT=6（按尝试计），最多一个处理中请求，同一requestId在10分钟内不重复调用。限额只在单进程内存，重启重置，不是账单硬上限。取消会中止本地等待并尝试中断上游请求，已经执行的请求仍可能计费。服务器不保存照片或记录照片内容；未接入新收费服务或存储。

## Gemini 摄影规则

[照片分析 Agent 操作手册](docs/LucyCam-照片分析Agent操作手册.md) 是构图规则来源。服务端固定发送 A 核心规则 + 当前接口对应的 B1/B2，不发送 C–E 研究附录，不接受浏览器自定义模型或系统提示词。旧 `/api/compose` 的响应合同保留；新 `/api/guide-plan` 复用同一会话、并发和限额。

规则强调主体与环境的视觉关系、不同取景候选和有可见意图的场景风格；不按人脸机械裁切，不默认回退轻微清透，也不因portrait标签统一限制强度40。新配方默认建议75–90为待实拍校准起点，mono100可用于人像；没人或杂乱时按空间结构规划；严重无法定位的占位不作为追踪目标，改用本地参考图恢复。执行计划仍经有限数值、类型对应的区域保护和边界校验。规则版本 `photo-manual-1.4`，部署后可在 `/api/status` 的 `aiRulesVersion` 核验。修改手册A/B后执行 `npm run prompts:build` 更新服务端生成文件；测试核对正文与哈希防止规则漂移。

这表示代码已接入手册，不代表真实 Gemini 已认可手册或照片更好看。没有进行生产调用或审美盲测；需获授权的实拍照片，通过现有受保护页面验收。密钥和口令继续只留在 Render，不放聊天、测试或仓库。

## 可重现验证与回滚

`npm ci` → `npm run check` → `npm test`；首次浏览器验证先运行 `npx playwright install chromium`，随后 `npm run test:browser`。浏览器测试启动临时本地服务器，使用合成图像摄像头与模拟provider，但图像追踪运行真实OpenCV；不触发真实Gemini费用。额外10分钟追踪生命周期检查：`npm run test:soak`，结果写入忽略目录 `qa-results/tracking-soak.json`。短时诊断可通过 `SOAK_SECONDS` 调整，不能把缩短测试报告成10分钟。

[当前验收记录](docs/实时引导验收记录.md) 区分自动测试、真实Gemini和真实iPhone。旧相机已跑回归；完整iPhone拍摄成功率、10分钟整机内存、相册保存及真实流程录屏仍待用户设备验证。
